# NASA: Beyond Earth

A cinematic PowerPoint presentation by Aleksmat-dev exploring NASA's history, Apollo missions, life in orbit, Hubble and Webb, Mars exploration, and Artemis.

## Download the presentation

Download **NASA_BEYOND_EARTH.pptx** from the [presentation download](https://github.com/Aleksmat-dev/NASA-Beyond-Earth/releases/latest). The complete presentation is a Release attachment, so the embedded videos stay intact without adding a large binary to Git history. Access requires permission to this private repository.

- File size: 147,649,531 bytes (147.65 MB).
- 14 visible slides and one hidden References slide.
- 14 embedded MP4 videos. No external relationships were found in the package.
- SHA-256: `e30b36d401071612446b93a23ac5357aed767385aa20a0fe51d78bddf8504d5d`.

## Presenting

Open the downloaded file in Microsoft PowerPoint for Windows and press **F5**. Advance with a click or the right arrow key. The presentation is designed to start each video automatically, hold its final frame and wait for the next click. Slide 3 contains launch audio. Browser previews and other presentation apps may handle playback differently.

## Visuals and credits

The presentation combines NASA photographs and footage with animations made in Blender using NASA models, textures and data, plus original project elements. Animations are illustrative reconstructions. Credits are retained in the presentation notes and hidden References slide. See [SOURCES.md](SOURCES.md) for the accompanying source inventory.
